
# Website Health Checker

A simple Python tool for checking whether a website is responding to HTTP requests.

## Features

- Checks website availability
- Displays HTTP status codes
- Handles connection errors
- Accepts a website URL as a command-line argument

## Requirements

- Python 3

## Usage

Run the default check:

```bash
python3 health_check.py
```

Check a specific website:

```bash
python3 health_check.py https://www.python.org
```

## Purpose

A beginner DevOps project for practicing Python scripting,
HTTP networking, Linux, Git, and GitHub.
